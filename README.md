# LOGTANDEM

## Description

LOGTANDEM is a website developed with React JS and Tailwind CSS.
It allows users to discover the LOGTANDEM International office and its features.

## How to Run the Project Locally

### Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/SabriAya/LOGTANDEM.git
   ```

### Build and Run

1. Install dependencies and start the app:

   ```bash
   cd LOGTANDEM
   npm install
   npm start
   ```
